# Unit 0.1 golden dataset: OmniSupply client brief

Calibration cases for unit 0.1:
- s01-textbook (pass): complete, reference-grade client brief with clear stakeholder scorecards and zero buzzwords.
- s02-succinct (pass): concise and rigorous problem statement meeting all three stakeholder criteria.
- s03-detailed (pass): deep operational analysis covering intake channels, document variation, and contract citations.
- s04-buzzwords-fail (fail): uses AI and LLM buzzwords in the problem statement without describing operational mechanisms.
- s05-missing-cfo-fail (fail): omits financial constraints and unit cost metrics.
- s06-no-workflow-fail (fail): does not map the document lifecycle from intake to settlement.
