The platform uses four verification layers: Layer 1 runs automated pytest assertions for code correctness; Layer 2 uses an LLM judge for qualitative rubric compliance; Layer 3 uses code defense questions to catch outsourced work; Layer 4 uses video walkthroughs for milestone projects.
Layer 1 must run first because running LLM judges on broken or non-executing code is wasteful and unreliable.
Phase 11 business modules run in parallel from week one so engineers build client acquisition skills alongside technical abilities, preventing graduation without client opportunities.
