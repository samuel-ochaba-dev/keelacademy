### Defense in Depth Model
- Layer 1: Automated sandbox checks catching syntax errors, test failures, and exit codes.
- Layer 2: LLM judge scoring qualitative rubric items with direct quotes.
- Layer 3: Code interrogation interview verifying genuine code ownership and reasoning.
- Layer 4: Screen recorded walkthrough verifying end-to-end system execution.

Layer 1 checks filter out broken implementations immediately. An LLM cannot accurately grade code that fails basic execution contracts.
Phase 11 runs continuously across the 9-15 month duration to build sales and scoping competence alongside software engineering.
