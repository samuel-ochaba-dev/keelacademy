# FAQ: Unit 0.3 (Environment setup and provider keys)

## What should I do if an API key is accidentally committed to Git? {#api-key-leak}

Immediately revoke and delete the compromised key in your provider's dashboard. Even if you delete the commit or make the repository private, automated scrapers can capture keys within seconds. Generate a new key, add `.env` to your `.gitignore`, and configure your environment variables locally.

## Why do I get permission errors when running Docker commands? {#docker-permissions}

On Linux systems, the Docker daemon binds to a Unix socket owned by `root`. To run Docker without `sudo`, ensure your user is added to the `docker` group (`sudo usermod -aG docker $USER`) and re-login or run `newgrp docker`. Verify that `docker info` exits zero without errors.
