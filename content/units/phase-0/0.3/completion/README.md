# Unit 0.3 completion exercise: environment and security synthesis

Synthesize the architectural requirements of containerized development, provider spend controls, and API secret management.

## Prompt
Explain why containerized sandbox environments are essential for AI engineering verification, how provider spend limits prevent runaway API bills, and what security practices protect API keys in local development.

## Requirements
1. Explain how Docker containerization eliminates environment divergence and enforces resource/network limits.
2. Explain the necessity of hard monthly provider spend limits against recursive or runaway API loops.
3. Detail proper API key management practices (environment variables, gitignore, zero hardcoded secrets).
