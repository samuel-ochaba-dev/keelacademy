# Unit 0.1 completion exercise: state OmniSupply's problem

The worked example gave you a finished brief for a different company. Now write the same analysis for OmniSupply, from the facts in the lesson.

## Prompt
State OmniSupply's core operational problem in three plain sentences, without using the words AI, agent, or LLM. Then define success concretely for the operations manager, the compliance officer, and the CFO.

## Requirements
1. Describe the multi-format intake bottleneck (scanned invoices, packing slips, damage photos, dispute emails) and the two-to-three-day manual triage delay.
2. Give each stakeholder a measurable success bar, and make the three bars different from each other:
   - Operations management: throughput, turnaround time, specialist workload.
   - Compliance: verifiable audit trail, supplier contract and SLA citations, human sign-off.
   - Finance: cost per transaction, unit economics, predictable spend.
3. Keep technology vocabulary out of the problem statement. Name the pain, not the tool.
